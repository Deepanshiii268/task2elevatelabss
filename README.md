# Aura Flow • Daily Focus

A minimalist, glassmorphic task tracker and focus dashboard built with semantic HTML5, modern CSS, and vanilla JavaScript.

---

## ✨ Features

* **Ambient Glassmorphism UI:** Dark-mode aesthetic featuring radial background glow effects, smooth backdrop blur, and micro-interactions.
* **Dynamic Progress Tracking:** Visual progress bar and task counter that update in real time as tasks are completed.
* **Category Tagging:** Assign tasks to predefined contextual tags (💼 Work, 🌿 Personal, ⚡ Urgent).
* **Persistent Storage:** Tasks and completion states persist across sessions using browser `localStorage`.
* **Dynamic Date Header:** Displays the current date dynamically on initial load.
* **Zero Dependencies:** Pure vanilla JavaScript, CSS variables, and native browser APIs.
